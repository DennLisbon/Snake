# Snake

Snake is a simple recreation of the classic Nokia Snake game, built with JavaScript. It recreates the original gameplay, challenging players to control a growing snake, collect food, and avoid collisions.

Developed as a project to practice JavaScript and game development fundamentals.

## Features

- Classic Nokia Snake-inspired gameplay
- Snake movement and growth mechanics
- Food collection and scoring
- Collision detection

## Technologies

- JavaScript
- HTML
- CSS
